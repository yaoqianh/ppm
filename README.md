# 持仓追踪 · 辅助决策看板（独立复刻版）

一个**完全独立、可直接部署**的持仓管理看板。原 Kimi 版本无法再修改，本项目在还原其视觉与交互的基础上重建了整套计算引擎，并补齐了原站缺失的「历史调仓记录 / 收益盈亏统计 / 每日评分变化趋势 / 评分权重可视化配置」四个模块。

- 纯静态前端（HTML + CSS + 原生 JS，零外部依赖，离线可用）
- Python 计算引擎（行情抓取 → 技术指标 → 配置驱动评分 → 生成看板数据）
- 行情源：腾讯财经（实时 + 前复权日线），接口异常时可回落手填价格

## 二、快速开始

```bash
cd portfolio-dashboard

# 1) 拉取最新行情、重算评分、生成数据
python run_update.py

# 2) 启动本地预览（浏览器打开 http://localhost:8000）
python serve.py
# 或者一步到位
python run_update.py --serve
```

> **注意**：必须通过 HTTP 打开。直接双击 `index.html` 会因浏览器的本地文件安全策略（CORS）读不到 `data/dashboard.json`。

依赖：Python 3.9+，仅用标准库，无需 `pip install`。

## 三、每天怎么用

### 方式 A：只刷新行情（持仓没变）

```bash
python run_update.py
```

### 方式 B：持仓变了 —— 把最新持仓发给 AI

直接把你的持仓信息发给 AI，例如：

> 帮我更新持仓：腾讯控股 300 股 成本 441.14 港币；双环传动 2700 股 成本 35.85；
> 今天加仓了东方财富 500 股，成交价 18.75。

AI 会做三件事：

1. 更新 `data/positions.json`（持仓数量、成本价、策略模板分配）
2. 往 `data/trades.json` 追加一条调仓记录（自动计算已实现盈亏）
3. 执行 `python run_update.py` 重算全部评分并刷新页面

### 方式 C：自己改文件

`data/positions.json` 格式：

```json
{
  "holdings": [
    { "code": "00700.HK", "name": "腾讯控股", "template": "longterm",
      "shares": 300, "cost": 441.1378, "currency": "HKD", "note": "" }
  ],
  "watchlist": [
    { "code": "600900.SH", "name": "长江电力", "group": "价值" }
  ]
}
```

- `template` 可选：`trend`（趋势跟踪）/ `longterm`（长线监控）/ `divergence`（背离反转）/ `exit`（退出通道）
- `cost` 填**该币种本币**的成本价，市值与盈亏会自动按 `settings.json` 里的汇率折成人民币
- 代码后缀：`.SH` 沪市 / `.SZ` 深市 / `.HK` 港股

`data/trades.json` 里 `type` 为 `baseline` 的记录是迁移基线，不计入已实现盈亏；真实调仓请用 `"type": "normal"`。

## 四、评分体系（可配置）

### 四套模板

| 模板 | 维度 | 满分 |
|---|---|---|
| 趋势跟踪 | 结构25 + 动量30 + 量能15 + 滤网15 + 位置15 | 100 |
| 长线监控 | 估值分位35 + 位置安全垫20 + 周线结构20 + 基本面质量25 | 100 |
| 背离反转 | 周线强力20 + 日线强力20 + 价格vs价值20 + 假突破20 + 背离完备20 | 100 |
| 基本面/估值 | 基准50 + ROE / 净利率 / 营收YoY / 归母YoY / PE / PB 六项调整 | 0~100 |

### 合成公式

```
综合分 = 100 × Σ(维度得分 ÷ 维度满分 × 权重) ÷ Σ(权重)
```

默认 `权重 = 维度满分`，此时综合分等于原始总分。**只有启用的维度才进入分母**，停用的维度不影响其他维度的相对关系。

### 调整方式

1. **页面上实时调**：右上角「⚙ 评分配置」→ 拖动权重滑块 / 勾选启用 → 全站分数立即重算
2. **永久生效**：点「导出 JSON」，用导出的内容覆盖 `config/score_config.json`，之后 `run_update.py` 也会按新权重计算并写入历史快照

页面上的改动保存在浏览器 localStorage；换浏览器或清缓存会回到项目默认配置。

## 六、部署

纯静态，无构建步骤。

**任意静态托管**：把整个目录上传即可（GitHub Pages / Vercel / Netlify / 对象存储 / nginx）。

**nginx 示例**：

```nginx
server {
    listen 80;
    root /var/www/portfolio-dashboard;
    index index.html;
    location /data/ {
        add_header Cache-Control "no-store";
    }
}
```

若需要定时自动刷新，加一条 cron（每交易日 15:30）：

```cron
30 15 * * 1-5 cd /var/www/portfolio-dashboard && python3 run_update.py >> update.log 2>&1
```

## 七、数据与口径说明

- **行情**：腾讯财经公开接口，日线为前复权，默认取 320 个交易日
- **涨红跌绿**：遵循 A 股习惯（红涨绿跌）
- **汇率**：`config/settings.json` → `fx`，港股默认 0.86；请按实际情况调整
- **硬止损**：默认单笔浮亏 ¥15,000，硬止损价 = 成本 − (限额 ÷ 汇率) ÷ 股数
- **52周高低**：A 股由 252 日 K 线自算，港股优先用接口返回的 52 周高低
- **PE / PB**：A 股每次更新自动从行情接口刷新；港股 PB 接口不提供，可在 `fundamentals.json` 手填
- **ROE / 营收YoY / 归母YoY / 净利率**：免费接口不提供，需在 `data/fundamentals.json` 维护（当前为原看板迁移值，`net_margin` 为估算，请核对）。缺失的维度会从评分分母中剔除，**不会按 0 分处理**
- **历史评分**：首次运行会用历史 K 线回算最近 60 个交易日；之后每天追加一条快照

## 八、已知限制

- 估值分位用「价格 252 日分位」近似 PE 历史分位（免费接口无历史 PE 序列）
- 背离反转的「假突破」为启发式判断，非严格 Elder 定义
- 技术指标有滞后性，评分仅供辅助决策，不构成投资建议
